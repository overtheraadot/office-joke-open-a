One single-line joke about office life, at most 200 characters, for
make.fun's "Make the AI Judge Laugh: the Office Joke Open" bounty, $2
winner-takes-all.

The joke:

> Our office printer only ever jams on documents marked urgent, which makes it the most honest performance review in the building.

The angle is the office printer — the one machine in the office more
honest than the humans. It only ever jams on the documents marked
urgent, so the punchline turns the jam into the building's most honest
performance review.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes the single joke line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
